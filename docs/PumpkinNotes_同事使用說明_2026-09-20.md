# Pumpkin Notes 使用說明（給夥伴）

Pumpkin Notes 是我們的「影片變筆記」工具。貼一支影片，系統會做成一頁看得懂的圖文筆記：有截圖、有時間戳、有白話小辭典、最後三句話帶走。

**網址**：https://notes.pumpkinvrarai.com/
**登入**：用公司 Google 帳號（@pumpkinvrar.com）按「用 Google 登入」。

**怎麼用**
1. 右上角「＋ 新增筆記」，貼 YouTube 連結或上傳錄影檔，選一個書架，送出。
2. 到「收件匣」看進度，通常 3～6 分鐘做好。做好會出現在「筆記書架」。
3. 打開筆記：截圖旁的時間可以點，會跳到影片那一段。
4. 覺得值得看，按「收藏」；想推薦給大家，按「分享給團隊」寫一句為什麼，夥伴在「團隊共筆」就看得到。
5. 讀完可以在最下面寫「我的一句話」，只有自己看得到。

**注意**
- 筆記預設只有自己看得到，分享了才會出現在團隊共筆。
- 影片截圖會自動存到公司雲端硬碟「Pumpkin Notes 素材庫」，自己拍的照片、錄影檔請丟「04 夥伴上傳」：
  https://drive.google.com/drive/folders/1P_qA5brzC137GlEQm37tGlnxCgBl6fLL
- 卡住或做失敗，截圖告訴南瓜。
