# 南瓜數位筆記｜整理主機搬到 PC-01（給 PC-01 上的 AI 與人看）

## 這是什麼
「南瓜數位筆記」（Pumpkin Notes）＝把影片變成團隊用得上的筆記。網站：https://notes.pumpkinvrarai.com/
夥伴在網站貼影片 → Supabase `jobs` 表多一列 → **整理主機**（就是這台要跑的 `worker.py`）下載影片、抽幀、請 Claude 寫白話筆記、驗收、上架、歸檔到 Google 雲端。
整理主機以前跑在南瓜的 Mac，2026-09-21 起改到 **PC-01 常駐**。GitHub Actions 已實測 YouTube 擋雲端 IP（連標題都拿不到），所以一定要在辦公室 IP 的機器跑。

## 它怎麼跑（2026-09-21 起）
- **即時**：`worker.py` 用 Supabase Realtime 訂閱 `jobs` 表，有人送單同一秒開跑（Mac 實測 0 秒延遲）。
- **保險**：Realtime 斷線自動重連，期間改每 30 秒輪詢，不會漏單；平常另每 120 秒補看一次。
- **自癒**：`pc01/啟動整理主機.bat` 是外層看門狗，worker 當掉 30 秒後重開；worker 啟動時把上次中途掛掉的單重新排隊（第二次還掛就標失敗）。
- **壞了會講**：以下情況會發 Telegram 給南瓜（用 `config.json` 的 `telegram_bot_token`／`telegram_chat_id`，只 sendMessage，不 poll，可與公告欄 bot 共用 token）：
  1. 一張單做失敗（附網址、原因、單號）
  2. Realtime 連不上三次（已退回輪詢）
  3. worker 當掉（附錯誤）
  4. 看門狗連續 3 次重開失敗
  5. 上線／手動停止（靜音訊息）
  ⚠️ 限制：PC-01 整台關機或斷網時**不會**有通知（沒東西能發）。網站上的單只是排隊不會掉，開機後自動補做。

## 安裝步驟（照順序）
1. **程式**：`git clone https://github.com/terry12260201/pumpkin-notes.git C:\PumpkinPM\pumpkin-notes`（之後 `git pull` 更新）。
2. **skill 腳本**：worker 依賴 `pumpkin-digital-notes` skill 的 `scripts/`（prep_youtube／report_lib／check_report／pn_config）。來源二選一：
   - 私有庫 `git clone https://github.com/terry12260201/pumpkin-skills.git`，路徑 `pumpkin-skills\skills\pumpkin-digital-notes\scripts`
   - 或 Obsidian vault `_系統/skills/pumpkin-digital-notes/scripts`（與 Mac 本機一致）
   把路徑填進 `config.json` 的 `skill_dir`（第 5 步的小工具會問）。
3. **工具**：Python 3.11+、`winget install Gyan.FFmpeg`、`pip install -r worker\requirements.txt`（含 yt-dlp；yt-dlp 要常更新 `pip install -U yt-dlp`）。確認 `ffmpeg -version`、`yt-dlp --version` 都能跑。
4. **金鑰**（只有南瓜能給，不進 repo、不貼聊天室）：把 Mac 的 `~/.config/pumpkin-notes/config.json` 用 USB 或密碼管理器帶過來，放 `C:\Users\<帳號>\.config\pumpkin-notes\config.json`。裡面有 Supabase service key、Claude API key、Google OAuth（Drive 歸檔）、Cloudflare token。
5. **補這台的設定**：`python worker\pc01\加設定.py`，會問 `worker_name`（填 PC-01）、Telegram token／chat id（沿用 `C:\PumpkinPM\tg_listener\.env` 的 `TELEGRAM_BOT_TOKEN` 與 `NOTIFY_CHAT_ID`）、`skill_dir`；並把 Mac 的 vault 路徑改成本機 `~\PumpkinNotes\`。
6. **手動先跑一次**：`python worker\worker.py --once`，沒單會直接結束、有單會做完。看到「找不到 skill 腳本」→ 回第 2 步。
7. **常駐**：雙擊 `worker\pc01\啟動整理主機.bat` 確認 log 出現「📡 Realtime 已訂閱」與 Telegram 收到「🟢 上線」。再登記工作排程器（登入即啟動）：
   ```
   schtasks /Create /TN PumpkinNotes_Worker /SC ONLOGON /RL LIMITED /F /TR "C:\PumpkinPM\pumpkin-notes\worker\pc01\啟動整理主機.bat"
   ```
   （若 PC-01 已有其他常駐排程如 PumpkinBoard_Bot，照同一套方式即可。）
8. **驗收**：到網站送一支短片，收件匣 3～6 分鐘內變「已上架」，`worker\worker.log` 有「▶ 接單」到「✅ 上架完成」；Google 雲端「Pumpkin Notes 素材庫」多一組資料夾。
9. 通知南瓜「PC-01 已接手」，南瓜 Mac 那邊才停掉 worker（兩台同時跑不會壞：單會被先搶到的做，但要避免重複花 API 錢）。

## 壞了怎麼看
- `worker\worker.log`：每張單的接單／失敗原因；看門狗重開紀錄。
- 網站收件匣「失敗：…」的字就是 log 裡的原因；夥伴重送即可。
- YouTube 出現 `Sign in to confirm you're not a bot` → 這台 IP 被盯上，先 `pip install -U yt-dlp`，還不行找南瓜（可能要加 cookies）。
- Google 雲端歸檔失敗不影響上架（log 會寫「不影響上架」），refresh token 失效時在這台跑 `python worker\drive_store.py auth` 重新授權。

## 鐵則
- 金鑰不進 repo、不貼聊天室、不寫進 log。
- Telegram token 只拿來 sendMessage，**不要**在這支程式 getUpdates（同 token 兩個 poller 會互搶）。
- 這台不碰 Obsidian vault（vault_dir 指本機暫存），Obsidian 回寫是另一個待辦。
