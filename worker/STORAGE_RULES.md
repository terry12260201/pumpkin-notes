# 圖片與檔案怎麼存（2026-09-20 定案）

## 原則
1. **不留在任何人的電腦**：整理主機做完一篇，截圖、封面、報告上雲後，本機工作夾整個刪掉。
2. **兩份，各有用途**
   - **網站用（Supabase）**：報告網頁 `notes/`（私人，簽名網址）、封面 `covers/`（公開）、截圖 `img/<使用者>/<筆記代號>/01.jpg…`（公開網址，只有知道網址的人看得到）。網頁讀這裡，快、穩。
   - **人找用（Google 雲端「Pumpkin Notes 素材庫」）**：同一批檔案再放一份，用「年份／日期 標題」分資料夾，夥伴在雲端硬碟直接搜標題就找得到。
3. **尺寸**：截圖統一最寬 1280px、JPEG 品質 80、漸進式。一張約 80～120 KB，文字仍清楚。封面同規格。原始抽出的 60 多張幀只留報告用到的 12～16 張，其餘不存。
4. **容量估算**：一篇 ≈ 16 張 × 100 KB ＋ 封面 ＋ 網頁 ≈ 1.8 MB。20 人每週各 3 篇 ≈ 每年 5.6 GB（雲端硬碟）；Supabase 免費 1 GB 撐約 500 篇，滿了再升方案或清舊圖。

## Google 雲端資料夾（https://drive.google.com/drive/folders/1P_qA5brzC137GlEQm37tGlnxCgBl6fLL）
```
Pumpkin Notes 素材庫/
├─ 01 報告網頁/2026/2026-09-19 用 AI 生圖＋AI 建站.html
├─ 02 封面圖/2026/2026-09-19 用 AI 生圖＋AI 建站.jpg
├─ 03 影片截圖/2026/2026-09-19 用 AI 生圖＋AI 建站/01.jpg … 16.jpg
└─ 04 夥伴上傳（照片、錄影檔丟這裡）/   ← 夥伴自己放；整理主機之後會從這裡收件
```
命名規則：`日期 標題`（標題去掉 / : * ? " < > |，最長 60 字）。同名檔重跑會覆蓋，不會越積越多。

## 授權方式
用南瓜本人的 Google 授權（OAuth，只給「這個程式建立的檔案」權限），檔案屬於南瓜的雲端硬碟、算公司空間。設定在 `~/.config/pumpkin-notes/config.json` 的 `google_oauth`；第一次授權跑 `python3 worker/drive_store.py auth`。
